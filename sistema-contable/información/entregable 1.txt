Propósito y justificación del proyecto


El propósito del presente sistema contable es automatizar y optimizar los procesos contables que actualmente se realizan de manera manual, con el fin de mejorar la eficiencia, precisión y control de la información financiera de la clienta.






Descripción del proyecto y entregables
El sistema permitirá la gestión eficiente de Gestión de clientes, Gestión de Cuentas por Cobrar, Gestión de Cuentas por Pagar,Cobros, Gestión de Inventarios,Gestión de Cuentas Contables,Gestión de Activos Fijos,Contabilidad general, Gestión de Proveedores,Gestión de Usuarios y Seguridad,Estados Financieros.
centralizando la información en una única plataforma segura y confiable.











Requerimientos de alto nivel
Requerimientos del producto
El sistema deberá permitir la gestión de clientes, incluyendo la creación, consulta, actualización y eliminación de registros.
El sistema permitirá al contador registrar cuentas por cobrar mediante un formulario que incluya la selección del cliente, los datos de la factura, el monto total, el saldo pendiente y el estado de la cuenta, permitiendo su posterior consulta y actualización
El sistema deberá permitir la gestión de cuentas por pagar, mediante el registro de obligaciones financieras asociadas a proveedores, controlando los montos, saldos pendientes y el estado de cada cuenta, así como el registro y seguimiento de los pagos realizados.
El sistema deberá permitir el control de inventarios mediante el registro de productos, así como la gestión de entradas y salidas, permitiendo conocer en todo momento las existencias disponibles de cada producto.
El sistema deberá permitir la gestión del catálogo de cuentas contables, mediante el registro, consulta y actualización de cuentas, clasificadas por tipo y utilizadas en los asientos de contabilidad general.
El módulo de Contabilidad General permitirá la creación de asientos contables mediante un formulario que incluye la fecha, descripción y detalle por cuenta, controlando los valores de debe y haber, y validando el equilibrio contable del asiento.

El sistema deberá permitir la gestión de activos fijos mediante el registro, actualización y baja de los activos, controlando su información básica y su estado contable.
El sistema deberá permitir la gestión de proveedores mediante el registro, consulta y actualización de su información básica, facilitando su asociación con las cuentas por pagar y el control de las obligaciones financieras.
El sistema deberá permitir realizar cobros mediante el registro de pagos recibidos, el seguimiento de saldos vencidos y el control del historial de cobros asociados a las cuentas por cobrar.
El sistema deberá permitir la generación automática de estados financieros básicos (Balance General, Estado de Resultados, Flujo de Efectivo y Balance de Comprobación) a partir de la información registrada en la contabilidad general, permitiendo su consulta por período.
El sistema deberá permitir la gestión de usuarios y seguridad, gestionando accesos, roles y permisos.
El sistema deberá almacenar la información en una base de datos segura y confiable.
El sistema deberá garantizar la integridad y consistencia de los datos registrados.










Requerimientos del proyecto
El sistema estará compuesto por 11 módulos CRUD, según los requerimientos definidos.

El desarrollo se realizará utilizando el framework Laravel.

El proyecto deberá completarse dentro del plazo establecido.

El sistema deberá contar con una interfaz de usuario clara e intuitiva.

Se deberán realizar pruebas funcionales para validar cada módulo CRUD.

Se deberá entregar documentación del sistema, que incluya: Manual de usuario.
El sistema deberá entregarse en una versión funcional y operativa.










Objetivos
Objetivo
Indicador de éxito
Alcance: 
El proyecto consiste en el desarrollo de un sistema contable basado en la web, implementado con el framework Laravel, que integrará ocho módulos CRUD para la gestión de clientes, cuentas por cobrar y pagar, inventarios, contabilidad general, activos fijos, cobros y administración de usuarios. El sistema permitirá el registro, consulta, actualización y eliminación de información, garantizando la integridad, consistencia y seguridad de los datos mediante una base de datos confiable. Además, contará con una interfaz de usuario clara e intuitiva, documentación correspondiente y pruebas funcionales que aseguren su correcto funcionamiento dentro del plazo establecido.
El éxito del proyecto se medirá mediante la entrega de un sistema funcional y operativo dentro del tiempo definido, la correcta implementación y funcionamiento de los ocho módulos CRUD, la aprobación de las pruebas funcionales realizadas, la integridad y consistencia de la información almacenada, y la disponibilidad de un manual de usuario que facilite el uso del sistema por parte de los usuarios finales.








Cronograma (Tiempo)
El proyecto se realizará en un tiempo estimado de 2 meses.










Costo












Calidad

Se realizarán pruebas funcionales a cada módulo para verificar su correcto funcionamiento y el cumplimiento de los procesos contables definidos.

Premisas y restricciones
Premisas
El desarrollo del sistema se realizará bajo la premisa de que los usuarios contarán con acceso a un navegador web y conexión a internet para utilizar la aplicación. Se asume que la información proporcionada por el cliente para el diseño de los módulos contables será correcta y suficiente.

Restricciones
El proyecto deberá desarrollarse dentro del plazo establecido
El alcance del proyecto se limitará a los 11 módulos CRUD definidos, por lo que las funcionalidades adicionales serán evaluadas por el equipo de desarrollo.







Riesgos iniciales de alto nivel
Los principales riesgos del proyecto es el retraso en el cronograma debido a una mala estimación del tiempo necesario para desarrollar y probar los módulos CRUD. Existe también el riesgo de cambios o falta de claridad en los requerimientos por parte del cliente, lo que podría afectar el alcance y la calidad del sistema.

Requisitos de aprobación del proyecto

El proyecto será considerado aprobado una vez que el sistema contable sea entregado en una versión funcional y operativa, cumpliendo con los requerimientos establecidos. Todos los módulos CRUD deberán estar correctamente implementados y validados mediante pruebas funcionales. El sistema deberá garantizar la integridad, consistencia y seguridad de la información almacenada en la base de datos. Asimismo, deberá contar con una interfaz de usuario clara e intuitiva, documentación completa que incluya el manual de usuario.
