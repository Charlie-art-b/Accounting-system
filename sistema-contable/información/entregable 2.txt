Especificación de Requerimientos Funcionales
REF


Función o subfunción
Prioridad


Gestión de Clientes


RF-1.1
El sistema debe permitir registrar clientes ingresando su información (nombre, identificación, correo, teléfono, dirección, estado)
Alta
RF-1.2
El sistema debe permitir consultar los clientes registrados.
Alta
RF-1.3
El sistema debe permitir buscar clientes por el nombre o identificación.
Alta
RF-1.4
El sistema debe permitir actualizar la información de un cliente existente.
Media
RF-1.5
El sistema debe permitir eliminar clientes del sistema.
Media


Gestión de Cuentas por cobrar


RF-2.1
El sistema debe permitir registrar cuentas por cobrar asociadas a un cliente.
Alta
RF-2.2
El sistema debe permitir consultar las cuentas por cobrar por cliente.
Alta
RF-2.3
El sistema debe permitir actualizar el estado de una cuenta por cobrar.
Media
RF-2.4
El sistema debe permitir eliminar o anular cuentas por cobrar.
Baja

Media
RF-3.4

Baja


Gestión de Inventarios


RF-4.1
El sistema debe permitir registrar productos en el inventario (proveedor, producto, stock inicial, entrada, salida y existencia actual).
Alta
RF-4.2
El sistema debe permitir consultar el inventario.
Alta
RF-4.3
El sistema debe permitir actualizar productos del inventario.
Alta
RF-4.4
El sistema debe permitir eliminar productos del inventario. 
Media


Gestión de Contabilidad General 


RF-5.1
El sistema debe permitir el registro de asientos contables.
Alta
RF-5.2
El sistema debe permitir la búsqueda y filtrado del libro diario de asientos contables.
Media
RF-5.3
El sistema debe permitir la generación de balances contables, tales como balance general y estado de resultados.
Media
RF-5.4
El sistema debe permitir la modificación de asientos contables existentes, siempre que cumplan con las restricciones contables definidas.
Baja
RF-5.5
El sistema debe permitir la eliminación de asientos contables, bajo autorización correspondiente.
Baja
